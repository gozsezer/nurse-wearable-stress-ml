# Wearable sensor-based stress classification among shift-working nurses

**Status: documentation-only research portfolio entry; NOT an executable reproduction.**

## Study overview
15 nurses; Empatica E4; EDA, HR, temperature and accelerometry; 60-second windows. The study abstract reports 1D-CNN ROC-AUC 0.864, LSTM 0.857 and XGBoost 0.850. Participant-level LOSO variability was substantial.
